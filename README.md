# Hotel Gym Workout Tracker

This is a simple static workout tracker designed for GitHub Pages.

## Files
- `index.html` — the website

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the root of the repo.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your branch (`main`) and folder (`/root`), then save.
6. After GitHub publishes the site, your Pages URL will appear in the Pages settings.

## Notes
- Your workout data is stored in the browser on the device you use.
- Use the Export/Import buttons in the app to move your saved data between devices.
